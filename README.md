# 城市旅遊指南 ✈️

給台灣旅客的城市旅遊指南。每座城市都用同樣的格式整理景點、美食、交通、每日預算與建議行程。

🌐 網站：https://eva00921-prog.github.io/travel-city-guide/

## 專案特色

- **內容與版面分離**：城市內容都是 `data/cities/` 裡的 JSON，版面只有兩個模板
- **新增城市不用寫程式**：複製範本、填資料、登記，就會自動出現在網站上
- **AI 友善**：`AGENTS.md` 寫清楚專案規則，AI 讀完就能照同一套格式新增城市
- **自動檢查**：`scripts/validate.py` 與 GitHub Actions 會檢查每座城市是否符合規則
